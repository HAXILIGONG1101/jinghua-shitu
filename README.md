# 京华·仕途 V1.2

作者:**kris 雷**

一款以北京市为舞台的网页版单机官场模拟游戏。玩家从街道办基层岗位起步,处理政务事件、群众诉求、建设项目、人事协作和廉政风险,通过季度考核逐步晋升,走向不同结局。

## 本版定位

V1.2 已经按极简方案重构:

- 纯静态网页,不需要后端和数据库。
- 只保留五个页面:首页、游戏总览、政务工作、人事组织、个人档案。
- 只保留六项属性:政绩、群众满意度、组织信任、财政预算、社会稳定、廉政风险。
- 除角色名字外,所有操作都是点选按钮和选项,不需要输入文字。
- 默认轻松模式,第一次玩也能直接上手。
- 三档本地存档,自动保存,并支持导出和导入存档文件。
- 电脑与手机浏览器都能玩。
- 每次打开或刷新网页,先显示作者署名页 `kris 雷`。

## 怎么玩

1. 在首页点「新建游戏」,输入角色名字。
2. 在游戏总览查看六项属性、主线任务和本月事项。
3. 打开「政务工作」,看完事件说明后点选一个处理方案。
4. 处理完本月全部事项后,点「推进一个月」。
5. 每三个月自动进行季度考核,满足条件会晋级。
6. 36 个月后或廉政风险达到 70 时进入结局。

主线、支线、新手提示都直接显示在游戏总览中。新手不知道选什么时,优先选择“先核实、走程序、把事办成”的方案。

## 内容范围

- 1 个模拟区:东华区
- 1 个模拟街道:新桥街道
- 6 个社区示意区块
- 6 名关键人物
- 3 个建设项目
- 20 个左右事件
- 6 级职务
- 5 种结局
- 3 个本地存档位置

其中行政区划名称只用于位置示意;人物、项目、事件、财政和案件数值全部为模拟数据,不代表现实机构或个人。

## 本机运行

项目依赖 Node.js 22.5 或更高版本。

```powershell
cd C:\Users\32703\Desktop\京华仕途\packages\web
pnpm install
pnpm run dev
```

开发地址通常是 `http://127.0.0.1:5273/`。

## 生产构建

```powershell
cd C:\Users\32703\Desktop\京华仕途\packages\web
pnpm run typecheck
pnpm run build
```

网页产物位于:

```text
C:\Users\32703\Desktop\京华仕途\packages\web\dist
```

这是纯静态文件,可以直接上传到 Cloudflare Pages、GitHub Pages 或其他免费静态托管。

## 自动验收入口

浏览器回归测试会真实启动 Edge,检查作者页、角色创建、点选事件、月度推进、本地读档、四个页面、手机布局和完整 36 个月结局流程。

先启动预览服务:

```powershell
cd C:\Users\32703\Desktop\京华仕途\packages\web
pnpm run preview --host 127.0.0.1 --port 5273
```

再运行:

```powershell
node C:\Users\32703\Desktop\京华仕途\scripts\v12-e2e.mjs
```

测试截图输出在 `work/`。该项测试不需要额外安装 Playwright。

## 存档说明

- 存档保存在当前浏览器 `localStorage`。
- 换设备或清理浏览器数据之前,先在首页点「导出」保存 JSON 文件。
- 「继续游戏」会优先恢复最近一次自动保存。
- 每个存档位独立,互不覆盖。
